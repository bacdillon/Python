# Grocery List Categorizer

*Building LLM Applications with Ollama Models*

## Overview

This project building LLM Applications with Ollama Models, that takes a plain, unsorted list of grocery items and uses a locally running model to organize them. Grouping items into sensible categories (Produce, Dairy, Meat, Bakery, Beverages, and so on) and sorting each category alphabetically. 

It reads a plain text file of items, sends them to the model with instructions, and saves into organized result to a new file. The purpose is to build a simple, local LLM application, from reading input, through prompting a model, to producing usable output.
